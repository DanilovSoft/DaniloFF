# Визуальные тесты

Скриншотные тесты на Playwright: каждая страница сайта снимается целиком
на трёх языках и пяти ширинах экрана и сравнивается с эталоном.

45 снимков — 3 страницы (`index`, `about`, `contact`) × 3 языка (`de`, `ru`, `en`)
× 5 разрешений.

## Запуск

```bash
npm run test:visual           # сравнить с эталонами
npm run test:visual:update    # перезаписать эталоны после осознанной правки вёрстки
npm run test:report           # открыть отчёт прошлого прогона
```

Первый запуск скачает образ Playwright (~2 ГБ) и поставит зависимости — это
занимает несколько минут. Дальше прогон занимает секунды.

Любые флаги Playwright пробрасываются: `npm run test:visual -- --grep about`.

## Почему через Docker

Тесты идут внутри официального образа `mcr.microsoft.com/playwright`, а не в
браузере на вашей машине. Причина одна: отрисовка текста зависит от системы —
эталон, снятый в macOS, отличается от того же экрана в Linux или Windows на
тысячах пикселей сглаживания, и тесты становятся красными у всех, кроме автора.
В контейнере Chromium, шрифты и рендеринг одинаковы везде, поэтому эталоны в
репозитории лежат в единственном экземпляре.

Нужен запущенный Docker — больше ничего (Node и браузеры живут в образе).

## Если тест упал

Прогон кладёт в `tests/report/` HTML-отчёт: рядом показаны эталон, фактический
снимок и подсветка различий. Открыть: `npm run test:report`.

Дальше два варианта:

- вёрстка сломалась — чинить код;
- изменение задумано — обновить эталоны (`npm run test:visual:update`) и
  включить новые снимки в тот же коммит, чтобы в ревью было видно, что
  изменилось на страницах.

## Что внутри

| Файл | Зачем |
|---|---|
| `visual.spec.js` | Сами тесты: перебор страниц, языков и разрешений |
| `static-server.mjs` | Отдаёт сайт на `127.0.0.1:4173` во время прогона, без зависимостей |
| `__screenshots__/` | Эталоны |
| `../playwright.config.js` | Конфигурация: один проект `chromium`, допуски сравнения |
| `../scripts/visual-tests.sh` | Обёртка, которая запускает всё это в контейнере |

Язык страницы задаётся до загрузки через `localStorage['language']` — так же,
как это делает переключатель в шапке сайта.
